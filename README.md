# Метч Бот ТГ 1.5.0 🚀

Асинхронный Telegram-бот для знакомств и поиска общения. Проект построен на базе современных асинхронных библиотек Python, обеспечивающих высокую скорость работы и устойчивость к нагрузкам.

## 🛠 Технологический стек

*   **Язык:** Python 3.11+
*   **Фреймворк:** [aiogram 3.x](https://github.com) (Асинхронная работа с Telegram Bot API)
*   **База данных:** PostgreSQL
*   **Драйвер БД:** [asyncpg](https://github.com) (Высокопроизводительный асинхронный драйвер для работы с БД)
*   **Валидация данных:** [Pydantic v2](https://github.com) (Жесткая проверка анкет перед отправкой в базу данных)
*   **Работа с файлами:** [aiofiles](https://github.com) (Асинхронное сохранение медиафайлов и логов)
*   **Управление конфигурацией:** [python-dotenv](https://github.com) (Безопасное чтение переменных окружения)

## 📂 Структура проекта

```text
├── .venv/               # Локальное виртуальное окружение Python

│   ├── __init__.py

│   └── requests.py      # Асинхронные SQL-запросы (CRUD операции)
├── handlers/            # Обработчики команд, текстовых сообщений и колбэков
│   ├── __init__.py
│   ├── change_find_question.py # Изменение параметров поиска
│   ├── change_question.py      # Редактирование своей анкеты
│   ├── complaint_center.py     # Система жалоб и модерации

│   ├── my_question.py          # Просмотр собственной анкеты

│   ├── rules.py                # Правила сообщества
│   ├── settings.py             # Настройки профиля и приватности
│   └── to_back.py              # Логика кнопок возврата «Назад»
```

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd имя_репозитория
```

### 2. Активация виртуального окружения
*   **Windows:**
    ```bash
    .venv\Scripts\activate
    ```
*   **Linux / macOS:**
    ```bash
    source .venv/bin/activate
    ```

### 3. Установка пакетов
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Настройка файла конфигурации
Создайте в корне проекта файл `.env` и добавьте в него следующие переменные:
```env

TOKEN_TG=1234567890:ABCdefGhIJKlmNoPQRsTUVwXyZ  # Токен от @BotFather
DATABASE_URL=postgresql://user:password@localhost:5432/db_name  # Подключение к PostgreSQL
```

### 5. Запуск
```bash
python main.py
```
